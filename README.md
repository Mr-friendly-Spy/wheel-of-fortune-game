# wheel-of-fortune-game
# Игра "Поле чудес"

## Описание проекта
Упрощенная версия популярной игры "Поле чудес", реализованная на Python с консольным интерфейсом. Игра предназначена для одного игрока и включает систему уровней сложности, подсчет очков и ведение статистики.

## Установка и запуск

### Способ 1: Запуск как Python-пакета

Установка зависимостей (если есть)
pip install -r requirements.txt

Запуск игры
python -m wheel_of_fortune

### Способ 2: Создание исполняемого файла

Установка PyInstaller
pip install pyinstaller

Создание исполняемого файла
pyinstaller --onefile --console wheel_of_fortune/__main__.py --name WheelOfFortune

Запуск исполняемого файла
./dist/WheelOfFortune.exe

### Детальное описание модулей
1. 📄 __init__.py - Инициализация пакета
Назначение: Определяет публичный интерфейс пакета и импортирует основные компоненты.

2. 📄 __main__.py - Точка входа
Назначение: Запускает игру при вызове пакета как модуля.

3. 📄 game.py - Основной игровой движок
Назначение: Управляет всем игровым процессом и логикой.

Основные классы и методы:
Класс Game
__init__(self) - инициализация игры, загрузка рекордов;

setup_game(self) - настройка сложности и генератора слов;

play_round(self, word, lives, round_number) - логика одного раунда;

show_statistics(self, game_duration) - отображение статистики;

ask_to_continue(self) - запрос на продолжение игры;

run(self) - главный игровой цикл.

Ключевые особенности:

Управление состоянием игры (использованные слова, счет);

Интеграция всех модулей в единый процесс;

Обработка пользовательского ввода и отображение прогресса.

4. 📄 file_handler.py - Работа с данными
Назначение: Управление файлами слов и рекордов.

Основные функции:

random_word_generator() - ⭐ ГЕНЕРАТОР ⭐ - yields случайные слова без повторений;

load_words_count() - подсчет общего количества слов;

load_record() - загрузка рекорда из файла;

save_record(record) - сохранение нового рекорда.

5. 📄 decorators.py - Декораторы для логирования и времени
Назначение: Добавление дополнительной функциональности через декораторы.

Основные декораторы:

@timer

Измеряет время выполнения функций;

Форматирует время в "X мин Y сек";

Логирует результаты в консоль и файл.

@log_errors

Перехватывает и логирует исключения;

Сохраняет stack trace для отладки;

Продолжает выполнение после логирования.

6. 📄 utils.py - Вспомогательные функции
Назначение: Вспомогательные утилиты для UI и обработки ввода.

Основные функции:

display_word(word, guessed_letters) - отображает слово с угаданными буквами;

choose_difficulty() - выбор уровня сложности с валидацией;

get_player_input() - получение и валидация ввода игрока;

format_time(seconds) - форматирование времени в читаемый вид.

Ключевые особенности:
Защита от некорректного ввода.

7. 📁 data/ - Директория данных
   
words.txt

Одна строка - одно слово;

Кодировка UTF-8.

record.txt

Содержит одно число - лучший рекорд;

Автоматическое обновление;

Сохраняется между сессиями.

## 🎮 Правила игры "Поле чудес"
### 🎯 Основная цель
Угадать как можно больше слов из предложенного списка, сохраняя жизни и устанавливая новые рекорды!

### 🏁 Начало игры
### 1. Запуск и настройка
   
При запуске игра показывает ваш текущий рекорд;

Отображается общее количество слов в игре;

Предлагается выбрать уровень сложности.

### 2. Выбор уровня сложности
1. Легкий уровень   → 7 жизней ♥♥♥♥♥♥♥;
   
3. Средний уровень  → 5 жизней ♥♥♥♥♥;
   
5. Сложный уровень  → 3 жизни  ♥♥♥;

### 🎪 Игровой процесс
### 1. Отображение слова
Слово показывается в виде закрытых символов: ■■■■■■■■;

Каждый символ ■ представляет одну букву.

### 2. Ход игрока

Варианты действий:
🔤 Назвать одну букву - открыть конкретную букву;

📝 Назвать всё слово - попытаться угадать слово целиком.

Правила ввода:
✅ Можно: русские буквы, целые слова;

✅ Регистр не важен: "а" = "А";

❌ Нельзя: цифры, спецсимволы, пустой ввод.

### 3. Результаты хода
✅ Правильная буква:

Буква открывается во всех позициях;

Количество жизней не уменьшается;

Буква добавляется в список использованных.

❌ Неправильная буква:

Игрок теряет одну жизнь ♥;

Буква добавляется в список использованных;

Показывается сообщение об ошибке.

✅ Правильное слово:

Игрок немедленно выигрывает раунд;

Открывается всё слово;

Переход к следующему раунду.

❌ Неправильное слово:

Игрок теряет одну жизнь ♥;

Показывается сообщение об ошибке;

Игра продолжается.

### ❤️ Система жизней
### Потеря жизней происходит при:
❌ Названии отсутствующей буквы;

❌ Неправильной отгадке слова.

### 🏆 Система рекордов
### Учет результатов:
✅ +1 слово за каждое угаданное слово;

📊 Сравнение с предыдущим рекордом;

🎊 Уведомление о новом рекорде;

💾 Автосохранение лучшего результата.

### 🔄 Механика продолжения
### После каждого раунда:
Показывается результат (угадано/не угадано);

Обновляется счетчик угаданных слов;

Предлагается выбор:

"Да" - продолжить с новым словом;

"Нет" - завершить игру.

### При продолжении:
🔄 Жизни восстанавливаются до полного количества;

🎯 Счетчик слов сохраняется;

🔀 Выбирается новое случайное слово.

### 🏁 Условия завершения игры
### 1. Победа в раунде
✅ Игрок угадал слово;

➡️ Предложение продолжить.

### 2. Поражение в раунде
💔 Закончились жизни;

🔍 Показ загаданного слова;

➡️ Предложение начать заново.

### 3. Полная победа
🎉 Угаданы ВСЕ слова из файла;

🏆 Специальное поздравление.

### 4. Добровольный выход
👋 Игрок выбирает "Нет" при продолжении;

📊 Показ финальной статистики.

### 📊 Финальная статистика
### После завершения игры показывается:

🎯 Угадано слов: X из Y;

⏱️ Время игры: X мин Y сек;

🏆 Лучший рекорд: Z слов.

### 🎪 Особые возможности

📋 Показ уже названных букв;

🔄 Предотвращение повторных попыток.
